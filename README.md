**A curated library of 1,024 professional AI prompts** across 12 categories, with smart search, Ultra-Lock system, and one-click copy.

## Features

- **1,024 Prompts**: Professional prompts across UI/UX Design, Frontend Dev, Backend Dev, AI & ML, Data Science, DevOps, Mobile, Security, Product, Writing, Marketing, and Education
- **Smart Search**: Real-time filtering by keyword, role, or scenario
- **12 Categories**: Organized and color-coded for quick browsing
- **Ultra-Lock System**: Premium-locked prompts with gold lock indicators
- **One-Click Copy**: Copy any prompt to clipboard instantly
- **Stats Dashboard**: Track total prompts, categories, and unlocked count
- **Glassmorphism UI**: Dark theme with blue (#0074FF) accents

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Glassmorphism, flexbox, grid, custom properties
- **JavaScript** — Search engine, library logic, Ultra-Lock system, clipboard API
- **Deployment**: GitHub Pages

## Usage

1. Browse prompts by scrolling or searching
2. Click a prompt card to copy it
3. Use the category filter to narrow results
4. Premium prompts show with gold Ultra-Lock (🔒)
5. Stats update in real-time at the top
